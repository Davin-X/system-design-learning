## Key Concepts Learned:

### What is System Design?
- System design is the process of defining the architecture, components, modules, interfaces, and data for a system to satisfy specified requirements.
- Focuses on scalability, reliability, maintainability, etc.

### Scalability:
- Vertical scaling (scale up): Adding more power to existing machine
- Horizontal scaling (scale out): Adding more machines
- Trade-offs: Cost, complexity

### Reliability:
- System continues to work correctly even when failures occur
- Redundancy, fault tolerance

### Availability:
- Percentage of time system is operational
- Measured as uptime/(uptime+downtime)

### Client-Server Model:
- Client sends requests, server responds
- HTTP/HTTPS protocols
- Stateless nature

### Basic Components:
- Load Balancer: Distributes traffic
- Web Server: Handles HTTP requests
- Application Server: Business logic
- Database: Data storage
- Cache: Fast data access
